# Intelligent Document Processing Pipeline

A GenAI engineering project for automated document processing.

## Project Goals

- Document classification with LLMs
- Structured information extraction
- Azure-hosted LLMs via REST API and SDK
- Automatic prompt optimization with DSPy and GEPA
- Agentic workflows using LangGraph
- Evaluation, monitoring and deployment

## Tech Stack

Python, Azure, FastAPI, Pydantic, DSPy, LangGraph, Docker
